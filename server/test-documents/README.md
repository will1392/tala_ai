# Test Documents for Smart Pipeline

This directory contains sample documents for testing the smart document pipeline.

## Document Types

1. **sample-passport.jpg** - US passport sample
2. **sample-ticket.png** - Airline boarding pass
3. **sample-hotel.pdf** - Hotel reservation confirmation
4. **sample-foreign-doc.pdf** - French passport (for language detection)
5. **sample-itinerary.jpg** - Multi-page travel itinerary
6. **sample-brochure.pdf** - Tourism brochure (colorful, marketing material)

## Test Scenarios

These documents are designed to test:
- Visual analysis accuracy
- OCR text extraction
- Multi-language support
- Document type detection
- Relationship mapping
- Quality assessment

## Note

These are mock text representations. In production:
- Real image files would be used
- Actual PDFs with embedded text/images
- Various quality levels (blurry, skewed, etc.)
- Different languages and scripts
